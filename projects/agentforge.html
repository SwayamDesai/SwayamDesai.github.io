AgentForge

A multi-agent code-generation system where five specialized agents collaborate to write, review, secure, test, and document code. Built on a LangGraph state machine with a saga retry loop, MCP-based tool integrations, hybrid local/cloud model routing, and a production-grade infrastructure layer — ~20% over a single-model baseline on HumanEval.

01 Overview

A single LLM asked to "write, test, and document this" does all three mediocrely. AgentForge splits the job into specialists — a coder, a reviewer, a security scanner, a tester, and a doc writer — coordinated by a LangGraph state machine that decides what runs, when, and what happens when something fails.

The point isn't just more agents; it's making a multi-agent system reliable. Reviews run in parallel, a saga loop feeds critique back into targeted fixes, a circuit breaker fails over between local and cloud models, and every action is an immutable event so any run can be replayed end-to-end.

04 Reliability engineering

The infrastructure layer is what makes it a system rather than a prompt chain.

Circuit breaker & fallback

Per-provider failure tracking automatically fails over between Ollama and Claude, so a flaky endpoint degrades gracefully instead of killing the run.

Event sourcing

Every agent action is an immutable event in PostgreSQL. Any task can be replayed step-by-step — invaluable for debugging non-deterministic agent behaviour.

Episodic memory

A vector store of past task outcomes; at runtime, similar prior experiences are retrieved and injected as context so the system improves with use.

MCP tool integrations

Sandboxed filesystem tools, GitHub repo creation and push, and Playwright browser automation — the security-scanned agents actually build, commit, and UI-test real apps.

Two-layer caching

A Qdrant-backed semantic cache plus Anthropic prompt caching cut redundant LLM calls — cheaper runs without changing behaviour.

Durable task queue

Celery with a Redis broker runs tasks asynchronously and survives server restarts, so long-running agent jobs aren't lost on a redeploy.
