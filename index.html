About

Careful analysis,
engineering that follows through.

A model that does well in validation is only the start. The questions I find most interesting come after: does it hold up on data it hasn't seen, does it change a real decision, and is it worth the cost of running?

That thinking shows up across my projects — a pre-registered A/B test to decide whether a forecasting model is worth shipping, a semantic cache and reranker to make a clinical retrieval system fast and accurate enough to trust, an event log and circuit breaker so a multi-agent system degrades gracefully rather than silently.

I'm comfortable across the full workflow — framing the problem and running the analysis, building and tuning the model, wiring the serving layer, and setting up the monitoring that flags drift — on AWS, GCP, and Azure.
